# Python で学ぶ AI 講座テキスト 教材作成ガイドライン (Antigravity Rules)

## 対象
- ビジュアルプログラミング（Scratch等）の経験がある中高生

## このディレクトリの概要
- **目的**: 生徒がプログラミングを学習する上で参考にする学習用ドキュメント（1レッスン 45分想定）。
- **難易度・言葉遣い**: 高度な技術や応用部分は学習しない。使う言葉も簡単なものを使用し、中学校までに学習する範囲の内容であれば使用OK。
- **リスト制限**: 箇条書きリストは **最大3つ** まで（4つ以上になると閲覧率が下がるため）。
- **Pythonコードの制約**:
  - **`class` の絶対禁止**: クラスは一切使用せず、すべて関数と状態 `dict` を使用して記述してください。モジュール化が必要な場合は、別ファイルにコードを分けて記載するようにしてください。
  - **`global` の絶対禁止**: Pythonのコード例で `global` キーワードは絶対に使用しないでください。

## 授業設計と執筆のルール
- **授業の流れ**: 実際に講師や生徒が見ながらそのまま進められるよう、ステップバイステップで記述し、「先生、次は何をやればいいですか？」という質問が出ないようにする。
- **言葉と概念**: 難しい言葉や高校以上で学習する概念は使用しない。どうしても必要な場合は中学生でもわかるように短く説明するか、AIに聞くよう促す。
- **AIの活用**: 各回の途中や最後に「AIに〇〇のやり方を聞いてみよう」といったTipsを **必ず1つ以上** 入れる。
- **用語の注意**: 受講者の技術力を計るという意味での「テスト」という言葉は使用しない（動作確認の意味での「テスト」は使用可能）。
