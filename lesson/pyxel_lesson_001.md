## 📐 4. 座標系と16色パレット

### Pyxelの座標系
画面の位置は **X座標**（横）と **Y座標**（縦）で表します。

- **画面の左上が原点** `(0, 0)` です。
- **右に行くほど X が大きく**なります。
- **下に行くほど Y が大きく**なります（算数や数学のグラフとは上下が逆なので注意！）。

### 🎨 Pyxelの16色パレット
Pyxelでは0～15の「色番号」で色を指定します。

| 番号 | 色名 | 説明 |
| --- | --- | --- |
| 0 | 黒 | 背景色によく使う |
| 1 | 濃い青 | 夜空、深海 |
| 2 | 濃い紫 | 神秘的な表現 |
| 3 | 濃い緑 | 森、草 |
| 4 | 茶色 | 土、木 |
| 5 | 濃いグレー | 岩、建物 |
| 6 | 薄いグレー | 雲、コンクリート |
| 7 | 白 | 雪、光 |
| 8 | 赤 | 火、情熱 |
| 9 | オレンジ | 夕日、炎 |
| 10 | 黄色 | 太陽、光 |
| 11 | 緑 | 植物、自然 |
| 12 | 青 | 空、水 |
| 13 | インディゴ | 夜、宇宙 |
| 14 | ピンク | 花、かわいい物 |
| 15 | ピーチ | 肌色、あたたかい色 |

## 🔺 5. 図形を描いてみよう

画面に背景色をつけたり、図形を描いたりしてみましょう。

### ステップ 1：画面をクリアして背景色をつけよう
`draw()` 関数の中に `pyxel.cls(12)` を追加します。

```python
import pyxel

pyxel.init(160, 120)

def update():
    pass

def draw():
    # 画面全体を青色（色番号12）で塗りつぶす
    pyxel.cls(12)

pyxel.run(update, draw)
```
- **どんな状態になるか**：実行すると、真っ黒だった画面が「鮮やかな青色」になります！

### ステップ 2：キャラクター（顔）を描いてみよう
`draw()` の中に円（`circ`）や線（`line`）を追加します。

```python
import pyxel

pyxel.init(160, 120)

def update():
    pass

def draw():
    pyxel.cls(12)  # 青い背景

    # 顔（ピーチ色の円）
    pyxel.circ(80, 60, 20, 15)
    # 顔の輪郭（黒い枠線）
    pyxel.circb(80, 60, 20, 0)

    # 目（左右に2つの黒い点・円）
    pyxel.circ(75, 55, 2, 0)
    pyxel.circ(85, 55, 2, 0)

    # 口（赤色の直線）
    pyxel.line(75, 68, 85, 68, 8)

pyxel.run(update, draw)
```
- **どんな状態になるか**：青い背景の真ん中に、にっこり笑ったキャラクターの顔が表示されます！

## ✏️ 6. 文字と変数を使ってみよう

### ステップ 1：画面に文字を表示しよう
`pyxel.text(x, y, 文字列, 色)` を使うと、画面の指定した位置に文字を表示できます。

```python
import pyxel

pyxel.init(160, 120)

def update():
    pass

def draw():
    pyxel.cls(1)  # 濃い青背景

    # (10, 10) の位置に白色（色番号7）で文字を表示
    pyxel.text(10, 10, "Hello Pyxel!", 7)

pyxel.run(update, draw)
```
- **どんな状態になるか**：画面の左上に白い文字で「Hello Pyxel!」と表示されます。

### ステップ 2：変数を使って文字を表示しよう
名前や年齢を変数に入れて画面に表示してみましょう。

```python
import pyxel

# 変数の用意
name = "Taro"
age = 14

pyxel.init(160, 120)

def update():
    pass

def draw():
    pyxel.cls(1)

    # f文字列（f"..."）を使って変数の値を埋め込む
    pyxel.text(10, 10, f"Name: {name}", 7)
    pyxel.text(10, 20, f"Age: {age}", 10)

pyxel.run(update, draw)
```
- **どんな状態になるか**：画面の左上に「Name: Taro」（白字）と「Age: 14」（黄字）が表示されます！

## 🔍 8. 動作確認とバグの直し方

困ったときのチェックポイントです。

### よくあるトラブルと直し方

#### トラブル 1：画面が表示されずエラーになる
- **原因**: カッコの閉じ忘れや、全角スペースが混ざっている可能性があります。
- **対処法**: 赤い波線が出ている行の前後を見直し、半角英数で正しく書かれているか確認しましょう。

#### トラブル 2：描いたはずの図形が見えない
- **原因**: 背景色と同じ色で描いているか、描く順番が逆（図形の上に背景を塗りつぶしている）になっている可能性があります。
- **対処法**: `draw()` の先頭で `pyxel.cls()` を呼び出しているか確認し、色番号を変えてみましょう。

#### トラブル 3：文字が画面からはみ出る
- **原因**: X座標やY座標の値が大きすぎます。
- **対処法**: 画面サイズ（160×120）の中に収まるように X, Y の数字を小さく調整しましょう。
