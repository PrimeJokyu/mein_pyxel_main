## 🎯 3. ボールを右に動かしてみよう

### ステップ 1：コードを書こう
`lesson02.py` に以下のコードを入力しましょう。
ボールの位置（座標）を「辞書（`dict`）」という仕組みで管理します。

```python
import pyxel

# ボールの状態（座標）を辞書で用意する
ball = {
    "x": 50,
    "y": 60
}

pyxel.init(160, 120)

def update():
    # 毎フレーム（1/60秒）ごとにX座標を1ずつ増やす
    ball["x"] = ball["x"] + 1

def draw():
    pyxel.cls(1)  # 画面を濃い青色でクリア
    pyxel.circ(ball["x"], ball["y"], 8, 10)  # 黄色いボールを描く

pyxel.run(update, draw)
```

## 🏀 5. 画面の端で跳ね返らせよう

このままではボールが画面の外に消えてしまいます。画面の壁に当たったら跳ね返る処理を追加しましょう。

### ステップ 1：壁の判定（if文）を追加する
`lesson02.py` を以下のように修正します。

```python
import pyxel

ball = {
    "x": 80,
    "y": 60,
    "dx": 3,
    "dy": 2
}

pyxel.init(160, 120)

def update():
    ball["x"] += ball["dx"]
    ball["y"] += ball["dy"]

    # 左右の壁に当たったらX方向の進む向きを逆にする
    if ball["x"] <= 0 or ball["x"] >= 160:
        ball["dx"] = -ball["dx"]

    # 上下の壁に当たったらY方向の進む向きを逆にする
    if ball["y"] <= 0 or ball["y"] >= 120:
        ball["dy"] = -ball["dy"]

def draw():
    pyxel.cls(1)
    pyxel.circ(ball["x"], ball["y"], 8, 10)

pyxel.run(update, draw)
```

### ステップ 2：実行して確認しよう
1. 実行ボタンを押します。
2. **どんな状態になるか**：ボールが4つの壁に当たるとポンポンと跳ね返る動きになります！

## ⏰ 6. 時間を使った動きの変化

`pyxel.frame_count` を使うと、プログラムが始まってからの時間（フレーム数）を計測できます。

### ステップ 1：時間で動きが変わるコードを書こう
`update()` の中身を以下のように書き換えてみましょう。

```python
import pyxel

ball = {
    "x": 80,
    "y": 60
}

pyxel.init(160, 120)

def update():
    # 60フレーム ＝ 1秒
    # 120フレーム（2秒）周期で上下の向きを変える
    if (pyxel.frame_count % 120) < 60:
        ball["y"] += 1  # 最初の1秒間は下へ移動
    else:
        ball["y"] -= 1  # 次の1秒間は上へ移動

def draw():
    pyxel.cls(1)
    pyxel.circ(ball["x"], ball["y"], 8, 10)

pyxel.run(update, draw)
```

### ステップ 2：実行して確認しよう
1. 実行します。
2. **どんな状態になるか**：ボールが1秒ごとに下、上、下…と交互に動きます。

## 🎪 7. 複数のボールを動かそう

辞書 `{}` をリスト `[` `]` に入れることで、たくさんのボールをまとめて管理できます。

### ステップ 1：リストを使ったコードを書こう

```python
import pyxel

# 3つのボールをリストでまとめて管理
balls = [
    {"x": 40, "y": 30, "dx": 2, "dy": 1, "color": 8, "size": 6},   # 赤いボール
    {"x": 80, "y": 60, "dx": -1, "dy": 2, "color": 12, "size": 8}, # 青いボール
    {"x": 120, "y": 90, "dx": 1, "dy": -1, "color": 10, "size": 4} # 黄色いボール
]

pyxel.init(160, 120)

def update():
    # for文で1つずつボールを取り出して動かす
    for ball in balls:
        ball["x"] += ball["dx"]
        ball["y"] += ball["dy"]

        if ball["x"] <= 0 or ball["x"] >= 160:
            ball["dx"] = -ball["dx"]
        if ball["y"] <= 0 or ball["y"] >= 120:
            ball["dy"] = -ball["dy"]

def draw():
    pyxel.cls(0)  # 背景色を黒にする
    for ball in balls:
        pyxel.circ(ball["x"], ball["y"], ball["size"], ball["color"])

pyxel.run(update, draw)
```

### ステップ 2：実行して確認しよう
1. 実行します。
2. **どんな状態になるか**：大きさ・色・スピードが違う3つのボールが画面内を跳ね回ります！

## 🔍 9. 動作確認とバグの直し方

プログラムがうまく動かないときに確認するポイントです。

### よくあるトラブルと直し方

#### トラブル 1：ボールが画面から消えてしまう
- **原因**: 壁の判定の数値が画面サイズを超えている可能性があります。
- **対処法**: `if ball["x"] >= 160:` のように、画面の幅（160）や高さ（120）に合っているか見直しましょう。

#### トラブル 2：ボールが壁に少しめり込んでから跳ね返る
- **原因**: ボールの中心位置だけで判定していて、半径を計算に入れていないためです。
- **対処法**: 半径が `8` のボールの場合、`if ball["x"] <= 8 or ball["x"] >= 160 - 8:` のように半径分だけ引いた位置で判定しましょう。

#### トラブル 3：エラーが発生して動かない
- **原因**: 辞書のキー名（`"x"` や `"dx"`）のスペルミスや、コード内に全角スペースが混ざっている可能性があります。
